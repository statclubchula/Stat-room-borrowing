# คู่มือตั้งค่า Supabase (เฟส 1) — ฉบับภาษาไทย

Supabase = ฐานข้อมูลออนไลน์ฟรี ที่เว็บยืม-คืนจะใช้เก็บ "คลังอุปกรณ์" และ "ประวัติยืม-คืน"
เพื่อให้ทุกคน/ทุกมือถือเห็นข้อมูลชุดเดียวกัน

> ⚠️ ขั้นตอนสมัครทั้งหมดต้องทำโดยเจ้าของบัญชีเอง (Claude สมัครแทนไม่ได้)

---

## ขั้นที่ 1 — สมัคร + สร้างโปรเจกต์

1. เปิด **https://supabase.com** → กด **Start your project** / **Sign in**
2. ล็อกอินด้วย **GitHub** หรือ **Google** (ฟรี ไม่ต้องใส่บัตร)
3. กด **New project**
   - **Name:** เช่น `stat-room-borrowing`
   - **Database Password:** ตั้งรหัสอะไรก็ได้ → **จดเก็บไว้** (ใช้ยามฉุกเฉิน)
   - **Region:** เลือก **Southeast Asia (Singapore)** (ใกล้ไทยสุด เร็วสุด)
4. กด **Create new project** แล้วรอสัก 1–2 นาทีให้ระบบสร้างเสร็จ

---

## ขั้นที่ 2 — สร้างตารางข้อมูล

1. เมนูซ้าย → **SQL Editor** → **New query**
2. เปิดไฟล์ [`supabase/schema.sql`](./schema.sql) ในโปรเจกต์นี้ → **ก๊อปทั้งไฟล์** ไปวาง
3. กด **Run** (มุมขวาล่าง) → ควรขึ้น **Success**
4. เช็กว่าได้จริง: เมนูซ้าย → **Table Editor** → ควรเห็นตาราง `inventory` (มีของ 10 รายการ) และ `borrow_logs`

---

## ขั้นที่ 3 — คัดลอกกุญแจมาให้ Claude

1. เมนูซ้าย → **Project Settings** (รูปเฟือง) → **API**
2. ก๊อป 2 ค่านี้มาส่งให้ Claude:
   - **Project URL** — เช่น `https://xxxxxxxx.supabase.co`
   - **anon public** key (ในหัวข้อ *Project API keys*) — สายยาว ๆ ขึ้นต้น `eyJ...`

> 🔐 **anon key ปลอดภัยที่จะใส่ในเว็บ** (ออกแบบมาให้เปิดเผยได้ และถูกคุมด้วย RLS อยู่แล้ว)
> ❌ ส่วน **service_role key** ในหน้าเดียวกัน — **ห้ามส่ง/ห้ามใส่ในเว็บเด็ดขาด** เป็นกุญแจแอดมินสูงสุด

---

## เสร็จแล้วทำอะไรต่อ

บอก Claude ว่า **"รัน SQL แล้ว"** พร้อมแปะ **Project URL + anon key**
→ Claude จะทำต่อเฟส 2 (เชื่อมเว็บเข้ากับฐานข้อมูล) ให้เลยค่ะ
